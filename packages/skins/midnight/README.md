# Midnight Skin

> 午夜 — 极简暗色皮肤

深邃的夜空配色，长时间使用护眼专注。与 `aurora` 对称的暗色实现。

## 配色

| Token | 值 | 用途 |
|---|---|---|
| `--dsh-bg` | `#0f172a` | 全局背景（深海军蓝） |
| `--dsh-surface` | `#1e293b` | 卡片/面板 |
| `--dsh-text` | `#f1f5f9` | 主文字 |
| `--dsh-primary` | `#60a5fa` | 主色（亮蓝，暗底下更醒目） |
| `--dsh-border` | `#334155` | 边框 |

## 能力

- ✅ 自定义滚动条
- ✅ 优化 autofill 黄色背景问题
- ❌ 不改背景图
- ❌ 不改标题栏
- ❌ 不依赖其他插件

## 用作模板

适合作为纯换色暗色皮肤的起点。与 `aurora` 对比可以学习亮/暗色皮肤的对称实现。
