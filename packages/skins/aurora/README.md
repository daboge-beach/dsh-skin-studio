# Aurora Skin

> 极光 — 极简亮色皮肤

柔和的晨光配色，长时间使用不刺眼。通过 CSS 变量实现换色，不碰 DOM，回滚零残留。

## 配色

| Token | 值 | 用途 |
|---|---|---|
| `--dsh-bg` | `#f8fafc` | 全局背景 |
| `--dsh-surface` | `#ffffff` | 卡片/面板 |
| `--dsh-text` | `#0f172a` | 主文字 |
| `--dsh-primary` | `#3b82f6` | 主色（按钮、链接） |
| `--dsh-border` | `#e2e8f0` | 边框 |

## 能力

- ✅ 自定义滚动条
- ❌ 不改背景图
- ❌ 不改标题栏
- ❌ 不依赖其他插件

## 用作模板

这是 DSH Skin Studio 的两个示例皮肤之一（另一个是 `midnight` 暗色皮肤），适合作为纯换色皮肤的起点。
