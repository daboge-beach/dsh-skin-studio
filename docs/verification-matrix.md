## C. 待真实手测（步骤）

> 自动化浏览器（ZCode IAB）本会话输入桥不稳定，以下以人工步骤给出。
> 每条 ≤2 分钟。

1. **皮肤工坊端到端**：画廊 → 🎨 创作皮肤 → 填名称/选色 → 确认预览与
   对比度三个比值 → 「安装到本机」→ 已上传 tab 出现新卡片 → 点卡片试穿
   → 应用并保存。预期：全程无报错；对比度 <3:1 时安装按钮禁用。
2. **Modal 焦点行为**：任意弹窗打开后连按 Tab（焦点在弹窗内循环）、
   Shift+Tab 反向、Escape 关闭（焦点回到打开前的按钮）。
3. **冷启动恢复**：安装上传皮肤并应用 → 刷新页面。预期：皮肤自动恢复；
   控制台出现「已恢复 1 款上传皮肤」。
4. **试穿回滚**：试穿 → 退出还原 / 刷新。预期：回到原皮肤，无残留。
5. **视觉冒烟**：宽屏（≥1280）与窄屏（≈900）各截图画廊、设置抽屉、
   皮肤工坊三处，确认无布局断裂。注意吉祥物漫步为随机动画，对比截图
   时忽略其位置。

## 已知未覆盖 / 风险

- Modal 焦点陷阱（Tab 循环）为纯 DOM 行为，vitest 环境为 `node` 无
  DOM；已实现但依赖 C 条目 2 的人工验证（Escape 关闭已于 2026-08-28
  真实 DSH 验证）。
- 真实 IndexedDB（非内存降级）路径依赖浏览器环境，自动测试覆盖的是
  MemoryStore 后备；持久化语义由 C 条目 3 人工确认。
- 跨浏览器矩阵（Chrome/Edge/Safari、缩放 80%–200%）未建立，待社区
  反馈或 CI 浏览器基建。
