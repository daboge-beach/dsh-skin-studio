## 一、修炼体系速查（角色设定的底层规则）

为便于理解角色设定的合理性，先列《凡人修仙传》核心体系：

### 境界阶梯（下境界 → 上境界）

| 阶段 | 境界 | 寿元 | 关键节点 |
|------|------|------|----------|
| 下境界 | 炼气期（13 层） | ~100 岁 | 吸纳灵气、洗髓易经 |
| 下境界 | 筑基期 | ~200 岁 | 灵气凝液，可辟谷御剑 |
| 下境界 | 结丹期 | ~500 岁 | 凝金丹、炼本命法宝 |
| 下境界 | 元婴期 | ~1000 岁 | 元婴离体夺舍、婴火炼器 |
| 下境界 | 化神期 | ~2000 岁 | 元神融成，可调动天地元气 |
| 中境界 | 炼虚/合体/大乘 | 数万载 | 借用法则，渡大天劫 |
| 上境界 | 真仙 → 金仙 → 太乙 → 大罗 → 道祖 | 与天地同寿 | 仙窍、法则、斩三尸 |

### 灵根等级（由低到高）

- **伪灵根**：四行/五行混杂，修为极慢，多困炼气期
- **真灵根**：两到三行属性，速度中等，可筑基结丹
- **天灵根 / 变异灵根**：单一稀有属性，门派争抢的天才
- **隐灵根**：被血脉/体质遮蔽，特定时机显现，潜力特殊

### 核心术语
- **道侣**：双修伴侣（南宫婉是韩立正配道侣）
- **器灵**：寄身法宝之内的灵体（银月的特殊身份）
- **夺舍**：强占他人肉身，一生仅一次
- **本命法宝**：与修士性命相连的法器，损毁则反噬

## 二、韩立（主角）

### 基本信息
- **别称**：韩老魔、韩跑跑、二愣子（小名）
- **出身**：越国镜州青牛镇五里沟，山村穷小子，家中老四
- **身份**：七玄门记名弟子 → 黄枫谷 → 落云宗 → 青元宫主
- **种族**：人族（燕族人）

### 修炼体系
- **灵根**：**四伪灵根**（金、木、水、火，缺土）——资质平庸，全靠机缘与算计逆袭
- **境界轨迹**：炼气 → 筑基 → 结丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 真仙 → 大罗
- **核心功法**：
  - **长春功**：入门基础功法，奠基之用
  - **青元剑诀**：核心战斗体系（青竹蜂云剑的剑诀根源），缺陷是第四层起法力流失，但第六层法力比同阶多三分之一
  - **大衍诀**：神识修炼秘法，让他神识远超同阶
  - **元磁神光**：灵界所得，可破万法
  - **明王诀**：佛门炼体神功
- **本命法宝**：
  - **青竹蜂云剑**：七十二口飞剑组成的剑阵，标志性的本命法宝
  - **虚天鼎**：得自虚天殿的逆天古宝
  - **掌天瓶**：贯穿全书的核心外挂（催熟灵药、穿越时空），唯一知情者是银月
  - **辟邪神雷**：青竹蜂云剑蕴含的辟邪雷光
  - **风雷翅**：飞行至宝

### 性格特点
- **意志坚定**：认准目标绝不放弃，万险千难亦不动摇
- **心思缜密 / 腹黑**：江湖人称"韩老魔"，算无遗策
- **无利不起早**：极度务实，不做无把握之事
- **擅长逃命**："韩跑跑"外号来源，打得过就打，打不过就跑
- **低调隐忍**：不逞英雄、不好面子，藏拙是本能
- **果敢狠绝**：该出手时绝不手软，杀伐果断

### 外貌特征
- **相貌普通**：原著反复强调"相貌普通的青年"
- **皮肤黝黑**：山村出身，常年风吹日晒
- **眼神深邃**：表面憨厚，眼底藏锋
- **气质内敛**：人群中毫不起眼，唯独眼神偶尔流露锐利

### 核心经历
- **童年**：三叔介绍入七玄门，墨大夫收徒（实为夺舍阴谋）
- **逆袭**：以平庸四伪灵根一路杀到大罗道祖
- **情感**：道侣南宫婉、红颜知己紫灵/银月/慕沛灵/元瑶
- **终极目标**：追求大道，证道长生

### 视觉关键词（皮肤设计用）
青袍道人 · 竹剑 · 风雷翅 · 青竹蜂云剑阵 · 翠绿 + 墨黑配色 · 朴实无华但气场内敛

## 三、慕沛灵（悲情佳人）

### 基本信息
- **身份**：落云宗筑基期女修，药园管事
- **与韩立关系**：名义上的妾侍（实为义妹）
- **定位**：全书最令人唏嘘的女性角色之一

### 修炼体系
- **灵根**：**真灵根**（水木双系，偏阴寒）
- **境界**：筑基期（结丹未成，冲击元婴失败身陨）
- **功法**：**玄冰诀**（阴寒系功法，曾亲授韩立）
- **法宝**：
  - 玄冰双环
  - 寒冰刺
  - 粉色花瓣形法宝

### 性格特点
- **温婉内敛**：大家闺秀气质，不争不抢
- **执念深重**：对韩立的感情成了她的心魔
- **心灰意冷**：发现韩立始终视她为义妹后，心境崩塌
- **坚贞不屈**：被家族逼婚时坚决不从

### 外貌特征
- **容貌清丽**：气质如兰，眉目含情
- **粉衣罗裙**：标志性装束，柔美温婉
- **发饰桃花**：常以桃花、珠钗为饰
- **神情幽怨**：眉间常有化不开的轻愁

### 核心经历
- 被家族逼婚，对外谎称已被韩立收为妾侍以求脱身
- 韩立为突破瓶颈假戏真唱，收其为妾
- 跟随韩立参加天南交易会、赴极西之行
- 对韩立倾心，但韩立始终视她为义妹
- **结局**：冲击元婴期失败身陨，韩立到坟前祭拜悼念

### 视觉关键词
粉衣女修 · 桃花发饰 · 粉白配色 · 飘落桃花瓣 · 幽怨柔美 · 冰蓝色灵气点缀

## 四、银月（神秘器灵）

### 基本信息
- **别名**：雪玲、玲珑仙子
- **真实身份**：灵界银月妖狼族，玲珑仙子的两魂之一
- **与韩立关系**：红颜知己，曾为本命法宝器灵

### 修炼体系
- **体质**：**七星月体**（先天魂体，月属性变异，因祸得福觉醒）
- **境界轨迹**：器灵 → 化形 → 合体期 → 大乘期（韩立飞升仙界前）
- **功法**：
  - **忘情诀**（为进阶合体所修，因韩立产生心魔）
  - **月华诀**（银月狼族秘传）
- **法宝**：
  - **狼首玉如意**（其本体，韩立所得古宝）
  - 银月剑
  - 月轮

### 性格特点
- **温婉聪慧**：长期作为器灵陪伴，心思细腻
- **忠贞不二**：对韩立的主仆情义逐渐升华为情愫
- **隐忍克制**：知晓掌天瓶秘密却守口如瓶
- **神秘矜持**：身世复杂，气质疏离

### 外貌特征
- **银白色长发**：如月光倾泻
- **银白仙袍**：闪烁月华光泽
- **肌肤如雪**：白里透红，灵族气质
- **眼眸清冷**：偶尔化白狐相随，灵动狡黠
- **气质出尘**：不似凡间女子

### 核心经历
- 被魔界始祖元刹分魂夺舍，逃入人界变为器灵
- 韩立得狼首玉如意后，银月成为其器灵，主仆相称
- 唯一知道掌天瓶秘密的人
- 脱困回灵界后觉醒七星月体
- 为突破合体修忘情诀，因韩立生心魔，最终摆脱控制
- 一直跟随韩立，直到他飞升仙界前晋级大乘

### 视觉关键词
银袍仙子 · 月光倾泻 · 银白 + 冰蓝配色 · 星河背景 · 白狐灵兽 · 出尘冷艳

## 五、南宫婉（正宫道侣）

### 基本信息
- **身份**：掩月宗杰出弟子 → 落云宗长老 → 青元宫主母
- **前世**：甘如霜转世
- **与韩立关系**：正配道侣（正宫）

### 修炼体系
- **灵根**：**天灵根**（火属性，纯度罕见）
- **境界轨迹**：结丹 → 元婴中期 → 化神（意外飞升小灵天）
- **功法**：**素女轮回功**（轮回系上乘功法）
- **本命法宝**：
  - **朱雀环**（火属性至宝）
  - **诛邪刺**

### 性格特点
- **清冷高雅**：掩月宗门风，气质出尘
- **温婉深情**：对韩立一往情深，从血禁试炼结缘到终生守候
- **坚韧独立**：韩立飞升灵界后独守人界，自强修炼
- **端庄大度**：正宫气度，不争不妒

### 外貌特征
- **容颜绝美**：倾国倾城级
- **月白色宫装**：掩月宗服饰，高贵端庄
- **发髻高绾**：玉冠束发，正宫气象
- **眉目如画**：清冷中藏柔情
- **周身寒梅暗香**：气质凛然

### 核心经历
- **初遇**：血色禁地试炼，与韩立合力击杀墨蛟
- **结缘**：因触墨蛟淫囊与韩立发生关系，情根深种
- **道侣**：元婴中期与韩立正式结为道侣
- **分离**：韩立飞升灵界，她因修为不足暂留人界
- **飞升意外**：进阶化神时意外飞升至小灵天
- **重逢**：韩立进阶大乘后到小灵天将她寻回

### 视觉关键词
月白宫装 · 朱雀火环 · 月白 + 淡金配色 · 寒梅飘落 · 高贵端庄 · 清冷仙子

## 六、紫灵仙子（第一美女）

### 基本信息
- **真名**：汪凝
- **身份**：乱星海妙音门门主之女 → 魔界仙尊
- **定位**：韩立平生所遇第一美女

### 修炼体系
- **灵根**：**隐灵根**（罕见，魔道亲和，特定时机显现）
- **境界轨迹**：结丹 → 元婴 → 化神（得六极圣祖传承飞升魔界）
- **功法**：
  - **六极圣祖传承**（魔道顶级传承）
  - **妙音秘法**（妙音门家传，以音律惑敌）
- **法宝**：
  - **六极魔幡**
  - **紫灵珠**
  - **天魔舞**（音律类群攻法宝）

### 性格特点
- **风情万种**：第一美女的自信与魅力
- **洒脱果敢**：不拘小节，敢爱敢恨
- **谋略过人**：在乱星海势力纷争中闯出名声
- **情深意重**：为与韩立仙界重逢，选择留在魔界苦修
- **野心勃勃**：目标是成就仙尊之身

### 外貌特征
- **容颜绝世**：原著钦定"第一美女"
- **暗紫色罗裙**：妙音门装束，华贵妖娆
- **长发如瀑**：乌黑发亮，偶有紫光流转
- **眼角含情**：妩媚中带狡黠
- **周身异香**：妙音秘法所致

### 核心经历
- 出身乱星海妙音门，门主之女
- 人界时韩立助其恢复自由身
- 获六极分魂传承，飞升魔界
- 韩立灭杀螟虫之母后助她摆脱六极控制
- **关键抉择**：放弃回灵界，选择留在魔界修炼，目标是成就仙尊之身在仙界与韩立重逢

### 视觉关键词
紫衣妖姬 · 暗紫 + 品红配色 · 星夜魔界背景 · 紫色灵雾 · 妩媚妖娆 · 第一美女气场
